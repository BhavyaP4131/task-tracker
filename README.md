# TaskBoard — Kanban Task Tracker

**Author:** Bhavya Patel
**Topic:** Agile Software Development — Task Tracking with Kanban Boards

## What this is
A simple Kanban-style task tracker built with plain HTML, CSS, and
JavaScript (no frameworks). Users can:

- Add a task with a title, due date, and starting status
- See tasks organized into three columns: **To Do**, **In Progress**, **Done**
- Drag and drop a task card between columns to update its status
- Delete a task
- Tasks are saved in the browser (`localStorage`) so they stay after a refresh

This project demonstrates the Agile concept of visualizing work in progress
using a Kanban board, where tasks move across a workflow instead of being
tracked in a flat list.

## Files
- `index.html` — page structure and layout
- `styles.css` — visual design (drafting-board / index-card theme)
- `script.js` — app logic: adding, storing, moving, and deleting tasks

## Running it locally
Just open `index.html` in any web browser — no build steps or installs needed.
